# X500 V2 × Jetson Orin Nano DevKit × RealSense D435i — 3D 프린트 마운트 (최종)

생성 `mount.py` (CadQuery) · 검증 `verify_fit.py` · 출력물 `out/` · 2026-11-08

## 구조 — FC 위 2층 선반 (판 위 부품을 다리로 넘어서 띄움)
드론 윗판은 이미 **KOA FC(가운데)·수신기 FS-iA6B(오른쪽)·배선 (다 20mm 미만, 재실측)**으로 차 있다.
그래서 링을 판에 눕힐 수 없고, **다리로 그 위로 들어올려야** 한다. 근거 그림 `out/assembly_section.png`.
```
        [=========== Jetson ===========]   ← 짧은 기둥 위에 나사 체결
          |                          |
        ==ring(얇은 7mm 사각 링, 가운데 OPEN)==  ← 부품들 위로 떠 있음
          |                          |
          | 다리 23mm                | 다리 23mm   ← 판 구멍(86x27)에 볼트
   ===[ KOA FC ]===[수신기]==배선==============  ← 드론 윗판 (부품 가득)
```
- **다리 4개(23mm)**: 링 모서리에서 아래로, 판 구멍 **86×27**에 체결. 판 위 부품 <20mm를 3mm 여유로 넘김. 수신기 쪽 면은 평평하게 깎아 틈 1.5mm.
- **링**: 젯슨 순정 프레임을 복제한 얇은 사각 링. 가운데 뚫림(무게↓·배선 접근).
- **젯슨 기둥 4개(8mm)**: 링 위로. 젯슨을 여기에 나사 체결(밑면 돌출 7mm를 8mm로 넘김)(순정 M2 나사, 파일럿 1.6mm).
- **카메라**: 링 앞 팔 끝(X=62)에 정면 브래킷.

| 다리 → 드론 윗판 (86×27 구멍) | **86 × 27 mm, M2.5** (공식 CAD 검증) | ✅ PASS |

- 젯슨 패턴: NVIDIA가 보드외곽↔홀좌표 비공개 → **실측 84.97×57.12**가 유일 근거(86×58은 구형 Nano).
- 드론 86×27: 공식 `x500v2-frame.step` 추출(86.0×27.0, M2.5), 실측 85.46×26.82와 오차 <0.6mm.

## ⚠️ 조립 전 실물 확인
1. **다리 23mm가 판 위 최고 부품을 넘는지.** 판 위 부품 다 <20mm(재실측) → 다리 23mm가 3mm 여유로 넘김. 더 높은 게 생기면 `STAND_H` 올림.
2. **수신기(FS-iA6B)와 오른쪽 다리 3mm.** 다리 수신기 쪽 면을 1.5mm까지 깎아 틈 1.5mm 확보(나머지 3면 꽉 참, 셀프탭 강도 유지).
3. **젯슨 앞 돌출부** 때문에 카메라 구멍은 X=62로 넉넉히 뺌(측정 불필요).

## 나사 명세 (전부 셀프탭)
- **A. Jetson → 기둥:** 젯슨에서 뺀 **원래 M2 나사 그대로**(나사산 2.0mm 실측), 기둥 위에서 셀프탭(파일럿 1.6mm).
- **B. 다리 → 드론 윗판:** **M2.5×8 볼트 ×4(보유분)**를 **판 아래에서** 끼워 다리에 셀프탭.
- **C. 카메라 → 브래킷:** M3 볼트 → 카메라 금속 나사산. **D. 브래킷 → 패드:** M3 셀프탭(2.5mm).

> ⛔ Jetson **모서리 4볼트**만 풀어 순정 플라스틱 받침 제거. WiFi 안테나 2개는 **스티커만** 떼서 분리(u.FL·선 금지). 모듈·팬 나사 안 건드림.

## 프린트 설정 (Bambu H2D, PLA)
- 레이어 0.2mm, 벽 4둘레, 인필 40~50%, 바닥 5겹.
- `jetson_tray`: **다리가 위로 서게 이미 뒤집어 export됨** → 베드에 그대로. 짧은 젯슨 기둥(6mm)이 발이 되어 링 밑에 가벼운 서포트만 생김.
